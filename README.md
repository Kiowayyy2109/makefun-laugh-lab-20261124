One short funny line for the One-Liner Laugh Lab competition: the excuse a
robot vacuum gives after eating a sock.

> Error 404: sock not found. I am the sock now.

## How to run

```sh
python3 main.py
```

This writes the line (45 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`,
falling back to `/output/entry.txt`. The program raises an error if the line
ever exceeds the 200-character limit.
